How does the minimum wage affect employment? 
This analysis uses spatial data to examine how much less likely people living around Seattle are to work jobs within Seattle compared to the City's minimum wage increase relative to the surrounding area (cross-border employment elasticity) following the City's min. wage. increase to $15 in April 2015.
Data are from the LEHD Origin Destination Employment Statistics ([U.S. Census Bureau]([url](https://lehd.ces.census.gov/data/))).
